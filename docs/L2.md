## reflection
1. Compact Constructor ใน Java Record ช่วยตรวจสอบความถูกต้อง (Invariants) ของข้อมูล เช่น name ไม่เป็นค่าว่าง และ email ต้องมีสัญลักษณ์ @ ได้อย่างกระชับก่อนที่ object จะถูกสร้าง ป้องกัน invalid state ได้โดยไม่ต้องเขียน boilerplate
2. การสลับบทบาท Driver และ Navigator ใน Pair Programming ช่วยให้ทั้งสองคนเข้าใจโค้ดทุกบรรทัด คนพิมพ์ (Driver) ได้โฟกัสที่การเขียนโค้ดและรันเทสต์ TDD ขณะที่ Navigator ช่วยระวัง edge cases ทำให้โค้ดมีคุณภาพและลดข้อผิดพลาดก่อนเปิด PR
